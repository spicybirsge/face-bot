Tech news API

A Discord bot archives tech news shared in the nerd stuff channel of the Face’s attic Discord server, and exposes it here via api. Open source self host it here

Browse the archive through the public JSON API or subscribe to the latest stories in an RSS reader. Both use the same archive, so saved stories stay available when Discord is offline.

JSON archive

GET /v1/news returns items and nextCursor. Stories are ordered newest first.

limit
Page size from 1 to 100. Defaults to 50.
category
Filter by nerds or nerds-ai. Omit this to include every category.
cursor
Pass the previous response’s nextCursor with the same category to request older stories. A null cursor means you reached the end.

Each item has an ID, title, publication time, optional summary and category, article links, and attachments if available.

raw_content contains the original Discord Markdown with the leading role ping removed. It is null for older entries awaiting a refresh.

RSS subscription

Add /feed.xml to your reader for the latest 50 stories.

RSS consumers can read the Markdown from face:raw_content when available. RSS omits characters that XML 1.0 cannot represent.

JSON and RSS both accept If-None-Match with the last response’s ETag. An unchanged response returns 304.
